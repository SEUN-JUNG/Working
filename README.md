# CH10 Local Viewer

Windows에서 IRIG 106 Chapter 10 파일의 **패킷 헤더와 데이터 영역**을 확인하는 Python 데스크톱 프로그램 초기 버전입니다. 파일 업로드, 네트워크 통신, 원격 분석 기능이 없습니다. Python 표준 라이브러리만 사용합니다.

## Windows 실행

1. python.org의 Python 3.12 이상을 설치합니다. 설치 옵션에서 Tcl/Tk 지원을 포함합니다.
2. 저장소 폴더에서 PowerShell을 열고 실행합니다.

```powershell
py -3 -m ch10viewer
```

`CH10 파일 열기`로 파일을 선택합니다. 패킷을 클릭하면 헤더 필드와 데이터 영역의 Hex를 확인할 수 있습니다. Hex 미리보기는 최대 64 KiB, 목록은 첫 10,000개 패킷을 표시합니다. 필드 추출은 전체 인덱스를 사용합니다. 데이터 전체를 메모리에 읽지는 않지만 패킷 인덱스와 추출 결과는 메모리에 보관합니다.

## 필드 추출

- 채널 ID: 십진수 또는 `0x` 표기. 빈칸이면 모든 채널입니다. 서로 다른 구조를 섞지 않도록 채널을 지정하는 것을 권장합니다.
- 오프셋: **CH10 기본/보조 헤더 다음 데이터 영역의 시작 기준**입니다. 채널별 데이터 헤더(CSDW)도 포함합니다. Ethernet 페이로드 시작 기준이 아닙니다.
- 자료형 및 바이트 순서: 장비 정의서에 맞춰 선택합니다.
- 최종 값: `원시 값 × 배율 + 보정값`입니다.
- 그래프 X축은 CH10 패킷 번호입니다. RTC는 CSV에 원시 100ns tick으로 저장합니다. UTC로 변환하지 않습니다.
- 짧은 데이터와 NaN/Infinity는 제외 개수로 보고합니다. 체크섬 경고 패킷도 조회·추출되므로 분석 전 확인하세요.

예: 채널 7의 데이터 영역 오프셋 8에 있는 big-endian int16을 0.1배하여 추출하려면 채널 `7`, 오프셋 `8`, 자료형 `int16`, 순서 `big`, 배율 `0.1`, 보정값 `0`을 입력합니다. 이는 사용 예시이며 실제 장비 구조를 의미하지 않습니다.

## 지원 범위와 한계

- 원시 CH10 패킷 스트림의 24바이트 기본 헤더, 48비트 RTC, 기본 헤더 체크섬, 보조 헤더 존재에 따른 데이터 위치, 패킷 경계·길이·잘림 검사를 지원합니다.
- 보조 헤더 자체의 시간/체크섬 해석, 데이터 체크섬 검증, TMATS 해석, 절대 시간 복원은 아직 지원하지 않습니다.
- Ethernet 데이터 타입의 내부 프레임 분리, IP/UDP 분석, 가변 위치 필드와 여러 샘플 추출은 아직 지원하지 않습니다. **CH10 패킷과 Ethernet 프레임은 같은 단위가 아닙니다.**
- PCAP, 네트워크 전송용 래퍼, 압축·암호화 파일은 지원하지 않습니다. 잘못된 동기값에서 추측하여 건너뛰지 않고 오류로 중단합니다.
- 파일 형식 버전 바이트는 원시 값으로 표시합니다. 최신 IRIG 106 개정 전체 지원 또는 적합성을 주장하지 않습니다. 공개 최신 규격과의 대조 및 실제 장비의 로컬 검증이 필요합니다.
- Windows GUI는 이 개발 환경에서 실행 검증하지 않았습니다. 합성 테스트는 파서 동작 검증이며 실제 장비 호환성의 증거가 아닙니다.

보안 파일은 공유할 필요가 없습니다. 사용 중 문제가 있으면 민감하지 않은 오류 문구, 규격 개정 연도, 필요한 필드의 상대 오프셋·자료형·단위 등 공유 가능한 정보로 보완할 수 있습니다. Hex/CSV에는 원본 정보가 포함되므로 조직 정책에 따라 로컬에 보관하세요.

## 테스트

```powershell
py -3 -m unittest discover -s tests -v
```

합성 데이터로 기본/보조 헤더 경계, filler 제외, 체크섬 경고, 잘림·길이 오류, 바이트 순서, 스케일링 및 비유한 값 처리를 검사합니다.
